Splitting the Difference

A project by Kiran McCulloch

The above image shows the lower 48 US States and the 10 Canadian Provinces, each split into two parts by a line that maximizes the area discrepancy but keep the population on either side as close to the same as possible. A label shows the percentage of the population within the smaller half above the abbreviation of the subdivision.

An interactive version of the initial map. Hover over city markers to see details, and click on subdivisions and their splits for more information.

About

Source Code The code I used to generate the splits can be found on my github. You need to have a shapefile or geojson for each area you want to analyze, and a raster for the same area named rast_NAME.tif. An example would be two files called Pennsylvania.shp and rast_Pennsylvania.tif. This is so that the program knows which raster goes with which vector layer.
